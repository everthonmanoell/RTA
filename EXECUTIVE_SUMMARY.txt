## WHY THIS MATTERS

Problem: Touch/swipe operations had no real-time feedback validation
→ Could miss touches, incorrect positions, signal loss - undetected

Solution: 3-layer safety approach:
1. Real-time feedback from app via ADB
2. Continuous signal monitoring during swipe
3. Pressure validation to prevent damage

Result: Level 1+ safety compliance with graceful degradation

## HOW IT WORKS

### Touch Flow (Pause-and-Listen)
1. Execute touch (0.5-1.0 sec)
2. Pause (0.3 sec post-contact)
3. Listen for ADB feedback (2.0 sec timeout)
4. Validate: position, signal strength, recognition status
5. Return: success flag + feedback data

**Safety Feature:** If ADB feedback timeout → returns fail, FSM retries

### Swipe Flow (Monitored)
1. Check initial signal (must be > 0.7)
2. Execute swipe along points
3. Monitor every 50ms:
   - Signal strength (abort if < 0.7)
   - Pressure (abort if > 700g)
4. Return: success flag + failure reason

**Safety Feature:** If threshold breached → abort gracefully, move to safe_pose

### Metrics (Real Position Tracking)
Before: Recorded assumed positions
After: Records actual positions from ADB feedback

**Benefit:** Detects missed touches, misalignment, calibration drift
